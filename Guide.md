🎯 My Recommendation for You

Given your existing exposure to programming, AI/ML, and computer vision, avoid starting every subject from zero.

Build this combination:

Software Engineering + AI/ML + Cloud + Cybersecurity

Start with solid programming and software engineering, then build AI applications and gradually add cloud and security expertise.

Your long-term advantage will come from being able to understand a problem, design a solution, build it, test it, and deploy it—not simply knowing the names of many technologies.
